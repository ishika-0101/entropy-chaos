## 📖 What is entropy-chaos?

entropy-chaos helps you check if your web services and APIs are safe. It uses smart methods to create security tests that find weak spots automatically. The software focuses on APIs, the parts of web apps that send and receive data behind the scenes. You do not need to be a security expert or programmer to use it.

This tool uses AI to make testing smarter. It tries many attack ideas to find weak points that hackers might use. It helps you spot issues early so you can fix them before they cause trouble.
